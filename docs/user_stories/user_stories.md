# User Stories

## US-01 Dodanie rezerwacji

### User Story

Jako klient salonu Kobido chcę dodać nową rezerwację wizyty, aby umówić się na wybrany termin.

### Kryteria akceptacji

- Użytkownik może podać imię.
- Użytkownik może podać nazwisko.
- Użytkownik może podać datę wizyty.
- Rezerwacja zostaje zapisana.

## US-02 Wyświetlenie rezerwacji

### User Story

Jako klient salonu Kobido chcę wyświetlić moje rezerwacje, aby sprawdzić zaplanowane wizyty.

### Kryteria akceptacji

- System wyświetla wszystkie zapisane rezerwacje.
- Widoczne są dane klienta.
- Widoczny jest termin wizyty.

## US-03 Anulowanie rezerwacji

### User Story

Jako klient salonu Kobido chcę anulować rezerwację, aby zrezygnować z wizyty.

### Kryteria akceptacji

- Użytkownik może wybrać rezerwację.
- Użytkownik może anulować wybraną rezerwację.
- System usuwa rezerwację z listy.

## US-04 Zakończenie programu

### User Story

Jako użytkownik aplikacji chcę zamknąć program, aby zakończyć korzystanie z aplikacji.

### Kryteria akceptacji

- Użytkownik wybiera opcję zakończenia programu.
- Program zostaje zamknięty.
