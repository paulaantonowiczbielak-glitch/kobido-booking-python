# Wymagania funkcjonalne

## FR-01 Dodanie rezerwacji

### Opis

Użytkownik może dodać nową rezerwację wizyty.

### Kryteria akceptacji

1. Użytkownik podaje imię.
2. Użytkownik podaje nazwisko.
3. Użytkownik podaje datę wizyty.
4. System zapisuje rezerwację.

### Oczekiwany rezultat

Nowa rezerwacja zostaje zapisana i jest dostępna na liście rezerwacji.

## FR-02 Wyświetlenie rezerwacji

### Opis

Użytkownik może wyświetlić wszystkie zapisane rezerwacje.

### Kryteria akceptacji

1. Użytkownik wybiera opcję wyświetlenia rezerwacji.
2. System pobiera zapisane rezerwacje.
3. System wyświetla listę rezerwacji.

### Oczekiwany rezultat

Użytkownik widzi wszystkie zapisane rezerwacje wraz z podstawowymi danymi.

## FR-03 Anulowanie rezerwacji

### Opis

Użytkownik może anulować istniejącą rezerwację.

### Kryteria akceptacji

1. Użytkownik wybiera rezerwację.
2. Użytkownik wybiera opcję anulowania.
3. System usuwa wybraną rezerwację.

### Oczekiwany rezultat

Wybrana rezerwacja zostaje usunięta z listy.

## FR-04 Zakończenie programu

### Opis

Użytkownik może zamknąć aplikację.

### Kryteria akceptacji

1. Użytkownik wybiera opcję zakończenia programu.
2. System zamyka aplikację.

### Oczekiwany rezultat

Program kończy działanie bez błędów.
